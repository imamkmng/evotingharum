Hubungkan ke Supabase Asli

Masukkan kredensial project Supabase Anda.

Cara Mendapatkan URL & Key:

  1. Buka dashboard di supabase.com
  2. Masuk ke menu Project Settings > API
  3. Salin Project URL dan anon public API key

Setup Tabel Supabase (SQL Script)

Buka menu SQL Editor di dashboard Supabase Anda, buat New Query, lalu paste script dari file supabase-schema.sql.

Panduan Deploy ke Cloudflare Pages (.pages.dev)

  • 1. Push folder project ini ke repositori GitHub atau GitLab.
  • 2. Buka dashboard Cloudflare > Workers & Pages > Create application > Pages.
  • 3. Pilih framework preset: Vite.
  • 4. Build command: npm run build | Output directory: dist.
  • 5. (Opsional) Tambahkan Environment Variables di Cloudflare: VITE_SUPABASE_URL dan VITE_SUPABASE_ANON_KEY.
